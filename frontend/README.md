Frontend quickstart

- Start backend (from `finance-ai-agent/backend`):

```bash
node server.js
```

- Open this folder with VS Code and use Live Server to open `index.html`, or simply open `frontend/index.html` in a browser.
- The frontend expects backend at `http://localhost:5000`. If your backend runs on a different host/port, update `app.js` `API_BASE` variable.
